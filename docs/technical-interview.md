# 기술면접 준비

`/technical-interview`와 홈의 **기술면접 준비** 버튼에서 접근한다. 기존 `/interview` 카메라 연습 화면과 서로 연결한다. `/bug-hunt`의 코드·문제·기록은 유지하며 홈의 코드 범인 찾기 버튼만 제거했다.

업로드한 `면접/오토에버1차.txt`의 38개, `면접/aws_sa_interview_questions_only.pdf`의 114개 질문을 모두 옮겼다. PDF 줄바꿈·단어 사이 공백과 문장 추출 순서를 정리했으며 질문의 의미는 유지한다. `technicalInterviewQuestions.json`에 원본 질문·주제·쪽수·고정 ID를, `technicalInterview.js`에 새로 작성한 답변과 주제별 연습 꼬리질문을 둔다.

기술 질문은 핵심 원리·사용 맥락·트레이드오프를 설명하고, 경험 질문은 지원자의 실제 경험으로 채울 구성 예시로 표시한다. 원자료 속 CTO·전공 전환·프로젝트 경험을 다른 사용자의 이력으로 단정하지 않는다. AWS 자료 마지막 2개는 지원자가 묻는 역질문으로 구분한다. 답변은 회사 공식 정답이나 합격 보장이 아니다.

회사·주제 선택, 질문과 답변 검색, 랜덤 질문, 답변 접기·펼치기, 이전·다음, 주제별 꼬리질문, 완료 표시와 완료 숨기기를 제공한다. 완료 상태는 브라우저의 주체별 키에만 저장하며 티어 문제 수에는 포함하지 않는다. 운영 DB의 개인정보 배지와는 별개다.

검증: frontend에서 `npm run check:technical-interview`, `npm run build`. 원문 대조 테스트에는 Poppler의 `pdftotext`가 필요하다. 152개 질문 모두를 원문 텍스트와 대조하고 답변 누락, 필터, 답변 숨김, 꼬리질문, 완료 저장과 계정 전환을 확인한다.
