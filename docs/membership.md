# 등급과 필기이론 접근

- 브론즈: 신규 방문자·신규 회원의 기본 등급.
- 실버: 반복 풀이를 제외하고 50문제 이상.
- 골드: 최초 적용 시 존재하는 회원 및 기존 방문자 기록에 부여하는 최소 등급.
- 다이아: 200문제 이상.
- 루비: 1,000문제 이상.

기존 회원·방문자는 풀이 수가 적어도 골드보다 내려가지 않는다. 기존 방문자의 자격은 브라우저의 방문자 ID로 유지된다. `MembershipRolloutService`는 최초 실행에서 `visitor_solved`, 닉네임 프로필, 기존 풀이 이벤트에 있는 방문자에게 골드를 부여하고 `membership_rollout`에 완료 표시를 남긴다. 재시작할 때 신규 방문자를 추가 승급하지 않는다. 기존 회원의 `base_tier`도 골드로 보존하며 새 가입은 브론즈를 명시한다. 기존 골드 방문자가 같은 브라우저에서 가입하면 골드를 이어받는다.

풀이 수는 문제은행별 문항을 한 번씩 세며, 같은 계정의 기기 수를 합산하지 않는다. 기존 순위 집계와 계정에 저장된 문항별 기록 중 큰 값을 사용한다. 학습 기록과 문제 수는 기존 서비스와 동일하게 클라이언트가 제출하는 방식이며, 이 등급은 별도의 서버 정답 검증 체계가 아니다.

`/api/v1/membership`이 현재 등급을 반환한다. 계정은 Bearer 토큰, 기존 비회원은 `X-Visitor-Id`를 사용한다. `/major` 계열 화면은 골드 이상을 요구한다. 이론 PDF는 프론트엔드 public 디렉터리에 두지 않고 서버의 `private-notes`에서 등급 검사 후 `/api/v1/theory/notes/{file}`로 제공한다. 이전 공개 PDF 파일은 새 프론트엔드 배포에서 제거된다.

닉네임은 1~20자이며 회원·비회원 사이에서도 중복을 막는다. 비교할 때 유니코드 NFKC, 소문자, 공백 정규화를 적용한다. `nickname_claims`의 고유 키로 동시 예약을 막고 계정/방문자 행을 잠가 변경 순서를 보존한다. 변경해도 사용자 ID·토큰·등급·풀이 기록은 유지된다. 회원은 변경한 닉네임으로 다음 로그인을 한다.

채팅 접속자 목록은 채팅창을 연 사람만 표시하고 30초마다 갱신하며, 갑자기 끊긴 접속자는 90초 후 만료한다. 공개 목록에는 방문자 ID 대신 임의의 참여자 핸들을 보낸다. 상대의 대결 신청 버튼은 주제별 문제 10개로 비공개 대결방을 만들고 해당 닉네임을 부른 참가 링크를 채팅에 전송한다.

검증: backend의 `bash gradlew test bootJar`; frontend의 `npm run check:membership`, `npm run check:lounge-chat`, `npm run check:account-retry`, `npm run check:exam-flow`, `npm run build`.
