# 웹 필수지식

전공노트 `/notes`에는 기존 169문답과 웹 필수지식 바로가기 하나를 표시한다. 새 50문답은 `/notes/web-essentials`에서 별도로 제공한다. 8개 주제 중 하나를 고르면 그 주제의 질문 목록과 선택한 문답 하나만 표시한다. 모바일에서는 주제 메뉴를 가로로 넘기고 질문 선택창으로 이동해 목차의 높이를 줄인다. 처음에는 웹 통신 주제를 열며 전체 50문답 검색과 이전·다음 이동을 지원한다. 출처 설명은 접어 두고 각 답변의 참고 자료는 함께 제공한다.

기존 169문답의 ID와 원문, 보완 답변 및 계정별 완료 저장 방식은 유지한다. 새 항목의 ID는 `web-` 접두사를 사용하며 기존 `cs-notes-v1` 기록에 함께 저장하므로 분리 전 체크도 유지한다. 원래 문답과 웹 문답의 진행률은 각각 계산하지만 다른 노트의 저장 기록을 버리지 않는다. 완료 체크는 시험 응시나 티어 문제 풀이로 집계하지 않는다. 이전 `/notes#web-…` 링크는 새 페이지로 리다이렉트하고 내 계정의 웹 문답 링크도 새 경로를 사용한다.

첨부한 NAVER D2 ‘백엔드 개발자를 꿈꾸는 학생개발자에게’(2018.06.21)의 주제를 참고했다. 첨부 원문과 사본을 저장소에 추가하지 않고 질문과 모범답안을 새로 작성했다. 답변을 NAVER의 공식 정답이나 원저자의 발언으로 표시하지 않는다. 각 답변에 참고 자료를 연결하고 기존 CC 표시가 있는 이식 문답과 출처 설명을 구분한다.

| 주제 | 문답 수 |
| --- | ---: |
| 학습 방향 | 6 |
| 웹 통신 | 8 |
| 데이터와 저장소 | 9 |
| 동시성과 실행 모델 | 5 |
| 보안 | 4 |
| 테스트 | 4 |
| 설계 | 5 |
| 개발과 운영 | 9 |
| 합계 | 50 |

원문의 경험과 판단을 보편 규칙으로 바꾸지 않도록 JOIN, 저장 프로시저, 비동기 I/O, MSA 등의 선택 조건을 설명했다. HTTP/3, R2DBC와 Java 21 가상 스레드는 2018년 이후의 보충임을 구분한다. 프로시저와 동기 복제의 동작은 DBMS와 설정에 따라 다름을 명시한다. 도구 사용만으로 안전성이나 성능이 보장된다고 설명하지 않는다.

작성 시 확인한 공식 문서의 소스:

- [HTTP core](https://github.com/httpwg/http-core/tree/bde37f634681bd5462568b73aa722af9c9a3ef5e)의 `rfc9110.xml`: 안전한 메서드, 멱등성과 재시도 의미
- [Spring Framework](https://github.com/spring-projects/spring-framework/tree/62c0f6f59e6be8cd4f20046cceceb5b31f56f63c)의 WebFlux 실행 모델, 단위 테스트와 테스트 트랜잭션 문서: 블로킹 호출, JUnit 범위, 다른 스레드의 롤백 한계
- [PostgreSQL](https://github.com/postgres/postgres/tree/4848fd6752ad6b88c5a066442df35ba208dfcec5)의 실행 계획과 고가용성 문서: EXPLAIN ANALYZE의 실제 실행, 복제 지연과 일관성
- [OWASP Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries/tree/9d41c054686e35fb56070b4b6271ae2829edea6a)의 SQL Injection, XSS, CSRF 예방 지침: 바인딩, 출력 문맥, 인증 정보의 자동 전송과 방어 수단

문서 사이트 직접 접속은 작업 환경의 프록시에서 차단되어 공식 Git 저장소로 위 자료를 확인했다. 그 외 참고 링크는 개념을 더 학습하기 위한 안내이며 모든 링크의 현재 HTTP 응답을 검증한 것은 아니다.

기존 전공노트 검사에 별도 화면 진입, 구 링크 리다이렉트, 주제별 목록, 한 문답 표시와 이전·다음, 전체 검색, 계정 전환과 완료 기록 보존 검증을 추가한다. 두 페이지가 같은 저장소를 공유해도 서로의 완료 기록을 유지하는지 확인한다. 기존 이식 원문과 보완 답변 검사는 그대로 실행한다.
