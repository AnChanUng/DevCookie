# 코드 범인 찾기

홈의 `🐛 코드 범인 찾기`에서 `/bug-hunt`로 진입한다. 로그인이나 골드 자격 없이 이용할 수 있다.

C·Java·Python 각 5개, 총 15개의 직접 작성한 디버깅 문제를 제공한다. 원인 줄과 이유를 모두 선택해 제출하면 각각 10점을 주고 수정 코드·해설을 공개한다. 두 부분을 모두 맞힌 경우에만 문제의 정답으로 기록한다. 한 판은 최대 5문제이며 언어 선택, 미풀이 우선 출제, 최근 오답만 다시 풀기를 지원한다. 실제 코드를 입력받거나 실행하는 기능은 없다.

`exam-progress:bug-hunt`에 기존 문제집과 같은 통계 형식으로 저장한다. 로그인하면 기존 `/exam/progress/bug-hunt` API로 동기화한다. 내 계정, 전체 오답 다시 풀기, 백업·복구와 순위의 동기화 목록에도 포함한다. 같은 문제의 반복 풀이는 새 문제 수로 늘리지 않는다. 오답노트에서는 원인 줄과 이유를 합친 객관식 문항으로 다시 풀 수 있다.

진행 중인 판은 `bug-hunt:round:v1:<주체>`에 브라우저별로 저장한다. 제출 답과 현재 문항을 복원하며 재접속으로 정답 통계를 중복 기록하지 않는다. 로그인 계정 변경 시 해당 계정의 판으로 전환한다. 판 자체는 기기 간 동기화하지 않는다. 저장소 사용이 차단돼도 현재 화면에서 게임을 진행할 수 있다.

검증: frontend에서 `npm run check:bug-hunt`, `npm run check:account-retry`, `npm run check:member-menu`, `npm run build`.
