# 면접 연습 학습 완료 저장

일반 면접·기초 개념·포트폴리오 질문의 완료 체크는 로그인 시 `chanung-completion-v1` 학습 기록으로 계정에 저장합니다. 새 로그인 세션과 다른 기기에서 같은 계정으로 불러올 수 있습니다. 비로그인 완료 체크는 현재 브라우저에 유지되며, 비로그인 기록을 다른 계정에 자동으로 섞지 않습니다.

기존 계정별 브라우저 완료 배열은 최초 읽기에서 이전합니다. 항목마다 done과 at을 저장하고 최신 변경을 병합해 완료 해제도 유지합니다. 체크는 화면에 즉시 반영하고 계정 저장 상태를 표시합니다. 실패하면 로컬 기록을 유지하며 창 복귀·네트워크 재연결·다시 저장으로 재시도합니다. 서버가 응답한 저장 요청은 기존 영속 대기열도 사용합니다. 기존 일반 학습 기록 API의 계정 인증·최신 항목 병합을 재사용합니다.

직접 입력한 연습 답변과 녹음은 이 기능의 동기화 대상이 아닙니다. 완료 항목은 기본적으로 숨기며 ‘완료한 답변도 표시’를 켜서 체크 상태를 볼 수 있습니다.

검증: `npm run check:chanung-completion`, `npm run check:chanung`, `npm run check:interview-audio`.
