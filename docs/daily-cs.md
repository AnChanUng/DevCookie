# 오늘의 CS와 오답노트

홈의 오늘의 CS 카드에서 개념을 읽고 바로 아래의 ‘오늘 배운 내용 확인하기’를 펼쳐 객관식 5문제를 푼다. 별도 메뉴나 모달로 이동하지 않는다. 홈의 오답노트는 기존 `/account/retry`로 연결하여 기업·문제집 구분 없이 한 번이라도 틀린 문제를 다시 푼다.

날짜는 기기의 시간대와 무관하게 한국 시간(UTC+9) 자정으로 계산한다. 같은 날짜에는 같은 개념과 같은 문제/순서를 선택한다. 페이지를 계속 열어 두어도 날짜가 바뀌면 새 개념과 미응답 상태로 전환하고, 백그라운드 탭이 다시 활성화될 때도 날짜를 확인한다. 개념 46개를 한 주기 안에서 중복 없이 섞는다.

문제은행의 주제와 해당 개념의 정규식으로 문제를 찾고, 지문·코드·보기가 같은 문항을 중복 제거하여 날짜별 난수로 5개를 선택한다. 관련 없는 과목으로 부족한 문제를 채우지 않는다. 모든 개념에 5개 이상이 있는지 검사한다.

제출 즉시 정답·해설과 오늘의 완료 수/정답 수를 표시한다. 응답은 날짜와 계정 식별자(기존 세션은 토큰)/방문자 ID별 로컬 저장소에 보관하여 같은 브라우저에서 새로고침하거나 접었다 펼쳐도 유지한다. 로그인 응답의 사용자 ID를 보관하여 앞으로 로그인한 계정은 다시 로그인하거나 닉네임을 바꿔도 동일한 응답 보관 키를 사용한다. 날짜가 달라지면 이전 답을 새 문제에 적용하지 않는다.

학습 기록은 기존 주제별 문제집(`topics`)의 원래 문항 ID로 저장하고 로그인 사용자는 기존 동기화 방식으로 서버에 올린다. 틀린 문항은 전체 오답노트에 포함된다. 같은 날 동일 문항을 다시 클릭하거나 화면을 다시 열어도 풀이 횟수를 추가하지 않는다. 오늘의 응답 선택 자체는 브라우저에 저장하며, 전체 참여자의 정답률 집계는 제공하지 않는다.

검사: frontend에서 `npm run check:today-cs`, `npm run check:account-retry`, `npm run check:member-menu`, `npm run build`.
