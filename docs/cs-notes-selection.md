# 전공노트 원문 이식

사용자 요청에 따라 자체 작성 CS 문답을 ksundong/backend-interview-question의 질문·답변 원문으로 교체했다. 원문 표현이나 기술적 주장, 예시를 임의로 수정·요약하지 않는다.

- 원문: https://github.com/ksundong/backend-interview-question
- 고정 커밋: 71f0300c379837e2f5666bbe19630a3d3fbc2bb2
- 포함: CS 관련 지식, 언어(Java·Spring·JPA·nodeJS·Python), 트러블 슈팅, 디자인 패턴, 테스트, 인프라/클라우드, 컨테이너, DevOps의 질문·답변 137개.
- 제외: 커뮤니케이션, 기타 질문 소절, 개인의 역량, 최신기술에 관심이 있는지. 문답이 아닌 면접 준비 안내와 기여 방법은 학습 카드에 넣지 않는다.
- 기업은행 대비용 빅데이터 32개는 원문과 구분된 별도 보충 과목으로 유지한다.
- 원문과 라이선스 문구는 frontend/src/data/vendor에 보관한다. 출처·저작자·이용조건은 화면에도 표시한다.
- 원문 답변 문자열은 그대로 보존한다. 화면 출력 시 잘못 닫힌 br 태그를 정규화하고 안전한 HTML만 렌더링한다. 빈 답변은 원문에 답변이 없음을 표시하며 자체 답을 추가하지 않는다.
- 원문 질문은 독립된 안정적 ID를 사용한다. 기존 완료 데이터는 삭제하지 않지만 서로 다른 질문 사이에 완료 상태를 임의로 옮기지 않는다. 빅데이터 ID는 유지한다.
- 답은 기본 숨김, 완료 항목은 기본 표시. 계정별 완료 저장과 재시도 동작을 유지한다.

검증: check:notes(계정·완료·답 보기), check:imported-notes(원문 일치·코드 블록·HTML 안전 처리), lint, build. 브라우저 접근 제한으로 시각 검증은 수행하지 않았다.
