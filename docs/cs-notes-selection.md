# 전공노트 기본기 선별 기준

목표는 키워드를 보고 정의·역할·기본 차이를 설명할 수 있는지 확인하는 것이다. 책의 전체 내용을 복제하거나 자격증 암기집을 만들지 않는다. 문항 수를 맞추기 위해 내용을 추가하지 않는다.

## 자료 확인

- 사용자 제공 『이것이 취업을 위한 컴퓨터 과학이다』 PDF: 목차(PDF 7–10쪽), 컴퓨터구조·운영체제·자료구조·네트워크·DB 개념도(PDF 23, 69, 133, 182, 264쪽)를 시각적으로 확인했다. 이미지형 PDF이므로 텍스트 추출 결과로 목차를 추측하지 않았다.
- 사용자 제공 『정보처리기사 실기 요약노트 (이론편)』: 22쪽 자료의 텍스트를 추출하고, 과목 목차와 소프트웨어 구축·DB·보안 관련 내용을 대조했다.
- 사용자 제공 네트워크 개념도: 물리/데이터 링크, IP, TCP/UDP, HTTP/TLS, 프록시/가용성의 기본 키워드를 점검했다.
- 기존 기술면접 블로그는 Java·객체지향 등 보조 키워드 참고용이다. 전체 범위를 결정하는 기준으로 쓰지 않는다.

문답은 직접 작성했다. PDF 원본, 캡처, 본문 추출 파일은 저장소에 포함하거나 사이트에 공개하지 않는다.

Java는 유지하고 빅데이터를 추가해 총 11과목 240문항으로 구성했다. IBK 채용프로세스의 디지털·IT 분야에 빅데이터가 포함된 것을 확인했다. 세부 키워드는 기본기 학습용으로 선별한 것이며 공식 세부 출제 목록이나 기출문제가 아니다. Hadoop·Spark 공식 문서와 scikit-learn 평가 문서를 대조했다. 제품 설정이나 수식 유도보다 개념 구분에 집중한다.

- https://ibk.incruit.com/jobinfo/ibk_prosess.html
- https://hadoop.apache.org/docs/stable/hadoop-project-dist/hadoop-hdfs/HdfsDesign.html
- https://spark.apache.org/docs/latest/rdd-programming-guide.html
- https://scikit-learn.org/stable/modules/cross_validation.html

제외: Spring/JPA 등의 프레임워크, 웹 요청의 전 과정을 길게 설명하는 질문, 제품 설정 절차, 세부 비용 산정 공식·도구명·공격명 암기, 분산 시스템 종합 설계. 빈칸 채우기나 소스 본문 복사는 하지 않는다.

기존의 의사코드, 장기·중기 스케줄러 상세 구분, 메모리 배치 알고리즘의 개별 암기 항목은 우선순위를 낮춰 제외했다. 남아 있는 항목 ID는 유지하고 추가 항목은 의미가 드러나는 고유 ID를 사용한다. 과거 완료 기록은 삭제하지 않는다.

## 동작과 검증

기본적으로 모든 미완료 질문이 보이며 답은 버튼을 눌러야 표시된다. 완료 표시와 계정 저장·재시도는 유지한다. `npm run check:notes`로 개념도 주요 항목 포함, 중복·빈 답변, 답의 기본 숨김, 완료 후 숨김·복원, 계정 분리, 기존 완료 상태 변환을 검사한다. 브라우저 접근 제한으로 실제 화면 시각 검증은 수행하지 않았다.
