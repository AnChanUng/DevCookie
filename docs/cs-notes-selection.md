# 전공노트 원문 이식

사용자 요청에 따라 자체 작성 CS 문답을 ksundong/backend-interview-question의 문답으로 교체했다. 이후 2026.10.15 사용자가 전체 내용 점검과 오류 정정·답변 보충을 요청하여 별도 보완 답변을 적용했다. 고정 원문은 보존하며 화면에서 보완 여부를 구분한다. 점검 범위와 참고 자료는 [cs-notes-review.md](cs-notes-review.md)에 기록한다.

- 원문: https://github.com/ksundong/backend-interview-question
- 고정 커밋: 71f0300c379837e2f5666bbe19630a3d3fbc2bb2
- 포함: CS 관련 지식, 언어(Java·Spring·JPA·nodeJS·Python), 트러블 슈팅, 디자인 패턴, 테스트, 인프라/클라우드, 컨테이너, DevOps의 질문·답변 137개.
- 제외: 커뮤니케이션, 기타 질문 소절, 개인의 역량, 최신기술에 관심이 있는지. 문답이 아닌 면접 준비 안내와 기여 방법은 학습 카드에 넣지 않는다.
- 기업은행 대비용 빅데이터 32개는 원문과 구분된 별도 보충 과목으로 유지한다.
- 원문과 라이선스 문구는 frontend/src/data/vendor에 보관한다. 출처·저작자·이용조건은 화면에도 표시한다.
- 원문 답변 문자열은 그대로 보존한다. 화면에서는 noteRevisions.js의 보완 답변을 ID 기준으로 적용한다. 빈 답변 31개를 채우고 오류·모호한 설명에 예시와 전제를 보충했다. 수정본은 ‘보완 답변’으로 표시하고 기존 원문 링크를 유지한다. 화면 출력 시 잘못 닫힌 br 태그를 정규화하고 안전한 HTML만 렌더링한다.
- 원문 질문은 독립된 안정적 ID를 사용한다. 기존 완료 데이터는 삭제하지 않지만 서로 다른 질문 사이에 완료 상태를 임의로 옮기지 않는다. 빅데이터 ID는 유지한다.
- 답은 기본 숨김, 완료 항목은 기본 표시. 계정별 완료 저장과 재시도 동작을 유지한다.

검증: check:notes(계정·완료·답 보기), check:imported-notes(원문 일치·코드 블록·HTML 안전 처리), check:revised-notes(보완 표시·빈 답변 해소·기존 ID 보존·전체 렌더링), lint, build. 브라우저 접근 제한으로 시각 검증은 수행하지 않았다.
