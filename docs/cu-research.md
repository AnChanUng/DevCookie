# 신협중앙회 IT 예상문제 조사 기록

## 2026-11-05 추가 조사 및 3세트 개편

[공식 채용사이트 공고](https://cu2.saramin.co.kr/service/cu2/3984/applicant/apply/recruit_default.asp)를 직접 확인했다. 공고명은 **2027년 신입직원 채용**이며 서류 접수는 2026.9.28~10.7, 전공필기는 2026.11.7이다. 5월 접수한 '2026 하반기' 공고 및 회원조합 공동채용과 구분한다.

- IT 직무상식은 객관식 40문항 / 40분이다.
- 범위는 소프트웨어 설계·개발, 데이터베이스 구축, 프로그래밍 언어 활용, 정보시스템 구축 관리다.
- 별도 코딩테스트는 2026.11.8, 알고리즘·SQL 4문항 / 120분이다.
- 공고는 과목별 문항 수, 보기 수, 실제 출제 문항을 제시하지 않는다. 이 문제집의 4지선다·과목 비중은 학습용으로 결정했다.

총 120문항, 40문항씩 3회로 변경했다. 1회는 기존 30문항의 ID를 보존하고 요구사항·테스트·형상관리·패턴 등 10문항을 새로 보강했다. 2~3회는 컴퓨터일반 및 저축은행중앙회 자체 예상문제 79개를 선별하고 JavaScript 1문항을 추가했다. 선별 문항에는 sourceBank/sourceQuestionId를 기록했다. 따라서 다른 문제집에서 이미 본 문항이 포함되며 신협 3회 사이에는 동일 문항을 중복 배치하지 않았다. 인터프리터 설명은 바이트코드 방식도 포함하도록 보완했다.

기존 일반 전산 분류를 공고의 4개 범위로 재분류했다. SQL 집계·정규화·키, C·Java 코드, 자료구조, OS 계산, 네트워크·보안, UML·유지보수·테스트를 고르게 포함한다. 40분은 목표 시간이며 기존 풀이 화면은 시간 제한 없는 방식이다.

아래 기록은 최초 30문항 작성 당시 조사 범위다.

2026-11-05 조사. 2020년 이후 자료를 검색했으나 모든 자료를 확보하지 못했다. 공개된 연도별 IT 전공 기출 원문과 과목별 출제 빈도를 확인하지 못했으므로 문항을 복원 기출로 표시하지 않는다.

## 문제 설계

DB / OS·컴퓨터구조 / 네트워크 / 정보보호·설계 / 프로그래밍·자료구조 각 6문항, 총 30문항을 직접 작성했다. 과목 배분과 40분은 학습용 설정이다. 실제 신협 출제 비중이나 시험 시간에 대한 추정이 아니다. SQL NULL 집계·조인, 페이지 교체·주소 계산, 서브넷·라우팅, 인가·암호, C·Java·Python 추적을 포함한다. 모든 문항에 단일 정답과 해설을 제공한다.
